# nickgen 기능정의서

## 개요
`@woowa-babble/random-nickname` 같은 "형용사 또는 지명 + 명사" 랜덤 닉네임 생성기. JS 모듈(`npm install github:HalroWorld/nickgen`)과 HTTP API 두 가지로 쓴다.

## 화면
없음 (API만). 위치 → 지역 변환은 부르는 쪽이 하고 `region`만 넘긴다.

## 기능
| 기능 | 상태 |
|---|---|
| `getRandomNickname(type)` 모듈 함수 (animals·characters), 접두사는 region이 있으면 그 지역 지명, 없으면 형용사 | 완료 |
| HTTP `GET /nickname`, `GET /types` | 완료 |
| 지역(`region`)을 받아 그 지역 지명으로 닉네임 생성 (서울·부산·제주 등 19개 지역) | 완료 |
