# 구조

- 기술 스택: Node.js 24 (의존성 없음, `node:http`)
- `index.js`: 단어 목록 + `getRandomNickname`
- `server.js`: HTTP API, 포트 `PORT` 환경변수 (기본 3000)
- `test.js`: `npm test`

## 주요 결정
- 외부 프레임워크 없이 `node:http`로 작성: 엔드포인트 2개뿐이라.
- 단어 목록은 원본 패키지를 복사하지 않고 새로 작성.
- 위치 → 지역(카카오 등)은 부르는 프로젝트가 한다: 이 프로젝트는 외부 키 없이 `region`만 받는 순수 닉네임 생성기로 둔다.
