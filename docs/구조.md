# 구조

- 기술 스택: Node.js 24 (의존성 없음, `node:http`)
- `index.js`: 단어 목록 + `getRandomNickname`
- `api/handle.js`: 요청 처리 (URL → 상태·JSON). 아래 둘이 같이 쓴다
- `api/server.js`: Node HTTP 서버 (`npm start`), 포트 `PORT` 환경변수 (기본 3000)
- `api/worker.js` + `wrangler.toml`: Cloudflare Workers (`npm run deploy`)
- `test.js`: `npm test`
- 운영 주소: https://nickgen.halro92.workers.dev (Cloudflare Workers `nickgen`). 배포는 `.env`의 `CLOUDFLARE_API_TOKEN`·`CLOUDFLARE_ACCOUNT_ID`를 불러 `npm run deploy`

## 주요 결정
- 외부 프레임워크 없이 `node:http`로 작성: 엔드포인트 2개뿐이라.
- 단어 목록은 원본 패키지를 복사하지 않고 새로 작성.
- 위치 → 지역(카카오 등)은 부르는 프로젝트가 한다: 이 프로젝트는 외부 키 없이 `region`만 받는 순수 닉네임 생성기로 둔다.
- 모듈과 HTTP API는 한 저장소에서 폴더로 나눈다: 단어 목록(`index.js`)을 한 곳에만 두려고. `package.json`의 `files`로 npm 설치 때는 `index.js`만 내려간다.
- HTTP API 배포는 Cloudflare Workers: 저장할 데이터·비밀값이 없는 짧은 요청이라 무료 한도(하루 10만 건) 안에서 관리 없이 돌릴 수 있고, 도메인이 이미 Cloudflare에 있다. wrangler는 의존성에 넣지 않고 `npx`로 버전을 고정해 쓴다.
